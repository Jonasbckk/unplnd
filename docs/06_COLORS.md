UNPLND Color System

Version 1.0

Design Goal

Colors should make users feel comfortable.
Opening UNPLND should feel like walking into a cozy café on a warm summer evening.
The interface must never feel cold.
Never clinical.
Never corporate.
The color palette is emotional before it is functional.

Brand Emotion

Every color should communicate one of these emotions:
Warmth
Comfort
Adventure
Trust
Optimism
Memories
Golden Hour
Calm
Premium

Soft Orange
No rainbow gradients.
No neon gradients.
No harsh transitions.

Shadows

Never use black shadows.
Always tint shadows slightly warm.
Opacity:
6–12%
Blur:
Large.
Soft.
Natural.

Transparency

Glass effects are allowed.
Only subtle.
Never overuse blur.
Background blur should feel like iOS.

Status colors

Maps

Maps should use muted colors.
No bright greens.
No saturated blues.
The map should never compete with the UI.
UNPLND owns the user's attention.

Album Colors

Albums should feel nostalgic.
Paper.
Polaroid.
Warm shadows.
Cream backgrounds.
Soft brown typography.
Very subtle vintage look.
Never fake Instagram filters.

                                                                        10
Accessibility

Minimum contrast:
WCAG AA
Prefer AAA whenever possible.
Never sacrifice readability for aesthetics.
Accessibility is premium.

Brand Recognition

If someone sees only the colors...
Without the logo...
They should still feel:
"This looks like UNPLND."
That is the goal.

Claude Instructions

Never introduce new colors.
Never use default system blue.
Never use Material Design colors.
Every new component must use this palette.
When unsure...
Choose the warmer option.
Warm always wins.
