47_COPYWRITING_GUIDE.md
UNPLND Copywriting Guide

Version 1.0
Priority: CRITICAL
Status: Foundation

Purpose

This document defines how UNPLND communicates.
Every word.
Every button.
Every notification.
Every error message.
Every future feature must sound like UNPLND.

Brand Voice

Warm.
Confident.
Optimistic.
Minimal.
Human.
Encouraging.
Never robotic.

                                                                         1
Personality

UNPLND is:
The friend who always knows what to do.
Never loud.
Never arrogant.
Never pushy.
Always helpful.

Writing Principles

Short.
Clear.
Positive.
Conversational.
Action-oriented.
One idea per sentence.

Tone

Friendly.
Premium.
Relaxed.
Natural.
Confident without sounding certain about things it cannot know.

                                                                         2
Reading Level

Easy enough for everyone.
Avoid complicated wording.
Avoid jargon.
If a 14-year-old understands it,
it's good.

Addressing the User

Always use:
You
Your evening
Your memories
Never use:
Customer
Consumer
End User

Headlines

Good
Ready for tonight?

Your next adventure starts here.
Bad

Errors

Good
Something went wrong.
Let's try that again.
Looks like you're offline.
We'll continue as soon as you're connected.
Bad
HTTP 500
Server Error
Unknown Exception
Technical language belongs in logs.
Not in the UI.

Empty States

Good
Your next memory starts here.
Adventure is waiting.
Let's plan something.
Bad
No Data Found.
Nothing Available.
Empty states should create excitement.

Notifications

Premium

Good

Bad
Upgrade before it's too late!
Premium should inspire.
Never pressure.

Grammar

Always correct.
Always natural.
Never intentionally misspell words.

Localization

Copy should translate naturally.
Avoid idioms that only work in one language.

Accessibility

Simple wording.
Short sentences.
Avoid ambiguous wording.
Screen readers should sound natural.

DO NOT

Do NOT sound like a chatbot.
Do NOT sound like a corporation.
Do NOT use clickbait.
Do NOT create urgency without reason.
Do NOT over-explain.

Golden Rule

Every sentence should feel like it was written by someone who genuinely wants the user to have a great
evening.

Claude Instructions

Before writing any text ask:
Would a real person naturally say this?
If not,
rewrite it.
Protect the voice of UNPLND at all costs.
