Profile Specification

Version 1.0
Priority: HIGH
Status: MVP

Purpose

The Profile is not an account page.
It is the user's personal story.
Every completed evening.
Every memory.
Every adventure.
Lives here.
Users should feel proud of what they created.

Philosophy

A profile should not show who you are.
It should show what you've experienced.
UNPLND celebrates moments.
Not followers.

Primary Goal

Encourage users to revisit memories.
Discover patterns.

Delight Checklist

✓ Profile feels personal.
✓ Memories are easy to revisit.
✓ Statistics feel meaningful.
✓ Map invites exploration.
✓ User feels proud.

DO NOT

Do NOT display follower counts.
Do NOT display like counts.

                                                                         8
Do NOT encourage comparison.
Do NOT turn the profile into another social network.
Do NOT clutter with unnecessary settings.
The profile exists for reflection.
Not validation.

Success Criteria

Users should occasionally open their profile
without needing to change anything.
Simply because they enjoy revisiting their memories.
That emotional behavior is success.

Golden Rule

The Profile is a digital travel journal.
Not an account screen.
Protect that identity.

Claude Instructions

Every profile element should answer one question:
"How can we make users appreciate the experiences they've already had?"
The profile should inspire the next adventure
by celebrating the previous ones.
Never optimize for social metrics.
Optimize for meaningful memories.
