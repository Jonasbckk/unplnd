UNPLND User Personas

Version 1.0

Introduction

UNPLND is built for real people.
Not demographics.
Not statistics.
Every product decision should optimize for at least one of these personas.
If a feature doesn't benefit any persona...
it probably shouldn't exist.

Persona 01

The Weekend Friend Group

Age
18–28

Description
A group of friends who meet every Friday or Saturday.
Every week starts with the same conversation.
"What are we doing?"
Nobody knows.
Everyone suggests something.
Nobody decides.

                                                                         1
Eventually they end up at the same places.

Pain Points
Decision fatigue.
Too many opinions.
No ideas.
Always doing the same activities.
Hours wasted planning.

Goals
Try new places.
Spend less time deciding.
Have memorable evenings.
Stay within budget.

Favorite Features
AI Planner
Group Planning
Weather Suggestions
Night Route
Albums
Sharing

Success
UNPLND creates an entire evening in under one minute.

                                                                         8
Users We Are NOT Building For

Professional travel agencies.
Business meetings.
Corporate event planners.
Conference scheduling.
Complex itinerary management.
Calendar power users.
Enterprise software.
UNPLND is a consumer lifestyle product.

User Promise

Regardless of who opens UNPLND...
They should immediately feel:
"This app understands me."

Claude Instructions

Every new feature must clearly identify:
Which persona benefits?
Which problem is solved?
How does this improve their experience?
If no persona benefits,
do not implement the feature.
Never build features for imaginary users.
Build for these personas.
