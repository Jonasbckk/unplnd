UNPLND Design System

Version 1.0
Priority: CRITICAL
Status: Foundation

Purpose

The Design System defines the visual language of UNPLND.
Every screen.
Every button.
Every card.
Every animation.
Every future feature must follow these rules.
Consistency creates trust.

Brand Personality

UNPLND should feel
Warm
Calm
Modern
Premium
Friendly
Minimal
Optimistic

Never corporate.
Never playful.
Never childish.

Design Philosophy

The interface should disappear.
Users should focus on planning experiences,
not learning the app.
Every interaction should feel obvious.

Dark Mode

Not an inverted light theme.
Custom palette.
Warm dark grays.
Muted colors.

Delight Checklist

✓ Calm.
✓ Elegant.
✓ Human.
✓ Consistent.
✓ Comfortable.
✓ Premium.

DO NOT

Do NOT use neon colors.
Do NOT use glassmorphism everywhere.
Do NOT use excessive gradients.
Do NOT overuse shadows.
Do NOT overcrowd screens.

                                                                        11
Do NOT chase design trends.
Timeless beats trendy.

Golden Rule

Every new screen should feel like it has always belonged to UNPLND.
Users should instantly recognize the product,
even without seeing the logo.

Claude Instructions

Before implementing any screen ask:
Does this look like UNPLND?
If the answer is uncertain,
redesign it.
Protect consistency above creativity.
Consistency builds premium products.
