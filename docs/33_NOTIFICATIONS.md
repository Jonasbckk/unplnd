Smart Notification System

Version 1.0
Priority: HIGH
Status: MVP

Purpose

Notifications should be genuinely helpful.
Never distracting.
Never manipulative.
Every notification should answer one question:
"Does this improve the user's evening?"
If the answer is no,
do not send it.

Philosophy

UNPLND should interrupt users as little as possible.
The app exists to help people experience life,
not constantly think about the app.

Delight Checklist

✓ Helpful.
✓ Friendly.
✓ Calm.
✓ Timely.
✓ Easy to dismiss.

DO NOT

Do NOT send daily engagement reminders.
Do NOT use fake urgency.
Do NOT spam users.
Do NOT manipulate with FOMO.
Do NOT send irrelevant promotions.

Success Criteria

Users should think:
"That notification was actually useful."
Not:
"Another app bothering me."

Golden Rule

Silence is better than a useless notification.
Every notification should earn the right to exist.

                                                                         8
Claude Instructions

Whenever adding a notification,
answer these questions:
Why now?
Why this user?
What value does it create?
If the answer is weak,
do not send it.
Notifications should feel like thoughtful reminders from a friend.
Not advertisements.
