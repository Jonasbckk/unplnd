Release Criteria

A release is allowed only if:
No critical bugs remain.
Core experience feels premium.
Mission remains intact.

DO NOT

Do NOT rush a release.
Do NOT launch with known critical bugs.
Do NOT sacrifice quality for deadlines.
Do NOT release unfinished premium features.

Golden Rule

Users never see the work behind a launch.
They only experience the result.
Make the first impression unforgettable.

Claude Instructions

Before tagging any production release,
run through this checklist completely.
If any critical checkbox is incomplete,
the release is postponed.
Quality is part of the product.
