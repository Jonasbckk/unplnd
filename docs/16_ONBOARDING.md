UNPLND Onboarding Experience

Version 1.0
Status: MVP

Purpose

The onboarding experience introduces the value of UNPLND.
It should create excitement.
Not explain features.
Users should understand the benefit without reading long text.

Success Metric

The user reaches the Home Screen in under 60 seconds.
Target completion rate:

          85%

Philosophy

Show.
Don't explain.
Let users feel the product.
Never overload with information.
Never ask unnecessary questions.

Success Criteria

The user should finish onboarding thinking:
"I want to try this tonight."
Not:
"I understand how the app works."
Emotion comes before explanation.

DO NOT

Do NOT explain AI.
Do NOT explain technology.
Do NOT show long paragraphs.
Do NOT ask for preferences.
Do NOT ask for favorite food.
Do NOT ask for hobbies.
Do NOT ask for interests.
Do NOT request unnecessary permissions.
Do NOT make onboarding longer than one minute.
