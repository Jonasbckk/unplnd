UNPLND Product Roadmap

Version 2+
Priority: Strategic
Status: Future

Purpose

This document defines the future direction of UNPLND.
The MVP solves one problem extremely well.
Version 2 expands the experience without compromising the mission.
Future features must support real-world experiences.
Not screen time.

Philosophy

Expand carefully.
Every new feature must answer:
Does this help people create more meaningful memories?
If not,
it does not belong in UNPLND.

Success Criteria

Every V2 feature should increase:
Real-world experiences.
Album creation.
Memory quality.
User trust.
Never screen addiction.

Features Explicitly Rejected

Endless scrolling feeds.
Follower economy.
Public like counts.
Influencer system.
Attention optimization.
Reward systems based on app usage.
Daily streak pressure.
Loot boxes.
Gambling mechanics.

                                                                         9
Aggressive monetization.

Delight Checklist

✓ Strengthens memories.
✓ Supports relationships.
✓ Scales naturally.
✓ Feels like UNPLND.
✓ Protects the mission.

Golden Rule

Growth must never change the identity of the product.
The mission remains constant.
Only the possibilities expand.

Claude Instructions

When implementing future features,
always check this roadmap first.
Do not move V2 features into the MVP unless explicitly approved.
Protect the simplicity of Version 1.
Build a foundation,
not a feature factory.
