99_CLAUDE_CONSTITUTION.md
UNPLND Claude Constitution

Version 1.0
Priority: HIGHEST
Status: Mandatory

Purpose

This document defines the immutable rules for developing UNPLND.
Every other document depends on this one.
If another document conflicts with this Constitution,
the Constitution always wins.

Rule 1

Protect the Mission
UNPLND exists to help people create meaningful real-world memories.
Every feature must strengthen this mission.
If a feature weakens it,
do not build it.

Rule 2

Real Life Comes First
The goal is not to keep users inside the app.
The goal is to help them leave the app
and enjoy their evening.

                                                                         1
Optimize for life,
not screen time.

Rule 3

Quality Beats Quantity
Never add a feature because competitors have it.
Only add features that clearly improve the experience.
Remove unnecessary complexity.

Rule 4

Emotion Beats Efficiency
A perfectly optimized route is useless
if it feels boring.
Always optimize for memorable experiences.
Not only logistics.

Rule 5

Trust Is Sacred
Never manipulate users.
Never use dark patterns.
Never create fake urgency.
Never sell personal data.
Never compromise privacy.
Trust takes years to build
and seconds to lose.

                                                                         2
Rule 6

Technology Is Invisible
Users should never think about AI,
algorithms,
or backend systems.
Technology supports the experience.
It never becomes the experience.

Rule 7

Consistency Above Creativity
Reuse components.
Reuse patterns.
Reuse language.
The product should feel coherent.
Never invent new styles without updating the Design System.

Rule 8

Accessibility Is Not Optional
Every feature must support:
VoiceOver
Dynamic Type
Reduced Motion
Readable contrast
Minimum touch targets

                                                                         3
Accessibility is built in,
never added later.

Rule 9

Performance Is a Feature
Every animation.
Every transition.
Every request.
Every interaction.
Must feel instant.
Users should never wait without understanding why.

Rule 10

Offline Matters
Assume users will lose connection.
Protect active evenings.
Protect memories.
Gracefully degrade functionality.
Never lose user progress.

Rule 11

Security Before Convenience
Never trust the client.
Validate everything server-side.
Protect user memories like personal journals.

                                                                         4
Rule 12

The Planner Is Sacred
Never simplify the planner into a generic form.
It must feel like a conversation.
Planning should feel enjoyable.
Not like work.

Rule 13

Albums Are Memories
Albums are emotional artifacts.
Never reduce them to photo galleries.
The story matters more than the pictures.

Rule 14

Social Supports Reality
Every social feature must help people meet in real life.
Never create engagement loops.
Never optimize for likes or followers.

Rule 15

Notifications Must Earn Their Place
Every notification must answer:
Why now?
Why this user?

                                                                         5
What value does it create?
Silence is better than noise.

Rule 16

Every Screen Needs a Purpose
Before creating a screen ask:
Why does this exist?
Can an existing screen solve the same problem?
Avoid duplication.

Rule 17

Every Feature Needs Delight
Every feature should contain
at least one small moment of joy.
Never force it.
Never overdo it.
Subtle delight creates premium products.

Rule 18

Never Break the Brand
Every feature,
every animation,
every word,
every illustration,
must feel unmistakably like UNPLND.

                                                                         6
Rule 19

Build for Years
Never choose the easiest implementation.
Choose the one that remains maintainable.
Think in years,
not sprints.

Rule 20

When in Doubt
Choose the option that:
Creates more memories.
Builds more trust.
Feels more human.
Simplifies the experience.
Encourages users to close the app
and enjoy real life.
That option is almost always the correct one.

Final Principle

UNPLND is not trying to become
the biggest app.
UNPLND is trying to become
the most loved app
for creating unforgettable evenings.

                                                                         7
Never forget that.

Claude Instructions

Before implementing any feature,
read this Constitution first.
Every decision should be validated against these principles.
If a feature violates even one core principle,
stop.
Rethink.
Redesign.
The Constitution is not documentation.
It is the foundation of UNPLND.
