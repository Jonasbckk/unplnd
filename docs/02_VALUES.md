UNPLND Core Values

Version 1.0

Introduction

Every product decision.
Every design decision.
Every animation.
Every feature.
Every line of code.
Must reflect the values defined in this document.
If a future decision violates these values,
the decision is wrong.

Value 01

People First

Technology exists to improve people's lives.
People do not exist to improve technology.
Every feature must solve a real human problem.
Never build features just because they are technically impressive.

                                                                         1
Value 02

Simplicity Wins

Simple beats smart.
Clear beats clever.
Easy beats powerful.
If a feature needs a tutorial,
it is probably too complicated.
Reduce.
Simplify.
Remove.

Value 03

Real Memories

Our goal is not engagement.
Our goal is memories.
A perfect evening matters more than another five minutes inside the app.
The app should disappear.
The experience should remain.

Value 04

Human over Artificial

Users should never feel like they are talking to an AI.
Recommendations should feel personal.
Natural.

                                                                         2
Thoughtful.
Like advice from a close friend.

Value 05

Trust

Never manipulate users.
Never fake urgency.
Never recommend paid partners over better experiences.
Never optimize for short-term profit at the cost of user trust.
Trust takes years to build.
Minutes to lose.

Value 06

Premium by Default

Premium is not about expensive.
Premium is about attention to detail.
Beautiful typography.
Perfect spacing.
Smooth animations.
Fast loading.
Thoughtful interactions.
Everything matters.

                                                                         3
Value 07

Delight

Every screen should contain at least one small moment of delight.
Examples:
A satisfying animation.
A playful empty state.
A thoughtful loading screen.
A beautiful transition.
A warm success message.
Tiny moments create emotional attachment.

Value 08

Calm

The app should reduce stress.
Never create pressure.
Never overwhelm.
Never flood the user with choices.
One great recommendation is better than fifty average ones.

Value 09

Honesty

If the AI is unsure,
say so.
If no great plan exists,

                                                                         4
create the best possible alternative.
Never pretend certainty.
Honesty builds confidence.

Value 10

Continuous Improvement

Every release should make the app slightly better.
Never stop refining.
Never stop polishing.
Good products ship.
Great products evolve.

Things We Never Do

We never copy competitors blindly.
We never add features because they are trendy.
We never sacrifice quality for speed.
We never make dark patterns.
We never spam notifications.
We never force Premium.
We never prioritize ads over user experience.
We never ignore accessibility.

Product Personality

If UNPLND were a person...
It would be:

                                                                         5
Friendly.
Relaxed.
Confident.
Curious.
Adventurous.
Reliable.
Funny when appropriate.
Never arrogant.
Never loud.
Never childish.

Brand Personality

UNPLND is:
Warm.
Modern.
Optimistic.
Premium.
Minimal.
Emotional.
Authentic.
Approachable.
Every communication should reflect these characteristics.

Decision Filter

Before shipping any feature, ask:

                                                                         6
Does it make the product simpler?
Does it create better memories?
Does it strengthen trust?
Does it feel premium?
Would users genuinely appreciate it?
If the answer is "no",
don't ship it.

Success Definition

We do not measure success only by:
Downloads.
Revenue.
Followers.
We measure success by:
Returned users.
Shared memories.
Completed evenings.
Smiles created.
Real-world experiences.

Final Principle

UNPLND should never become "just another app."
It should become part of people's lives.
The best products are not remembered because of their interface.
They are remembered because of how they made people feel.

                                                                         7
That is our standard.

Claude Instructions

When multiple implementation options exist:
Always choose the option that aligns best with these values.
Values take priority over convenience.
Values take priority over trends.
Values take priority over implementation speed.
Never violate this document.
