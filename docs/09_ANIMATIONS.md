09_ANIMATIONS.md
UNPLND Motion System

Version 1.0

Purpose

Animations are communication.
Animations explain.
Animations guide.
Animations reward.
Animations should never exist purely for decoration.
Every animation has a purpose.

Motion Philosophy

Think:
Apple
Airbnb
Arc Browser
Linear
Not:
Android Material
Gaming UI
Fancy Dribbble concepts
Animations should feel invisible.

Performance

60 FPS minimum.
Target
120 FPS on supported devices.
Never drop frames.
Prioritize smoothness over complexity.

Accessibility

Respect "Reduce Motion".
Provide fade alternatives.
Never force animations.

Signature Moments

Every user should remember:
The first generated route.
The album opening.
Completing an evening.
These animations deserve extra attention.

Golden Principle

Animations should make users smile.
Not notice.
If users actively notice the animation...
it is probably too much.

Claude Instructions

Never invent random animations.
Every animation must improve:
Understanding
Orientation
Emotion
Reward
If none apply...
Do not animate.
Motion should feel like Apple.
Not like Dribbble.
