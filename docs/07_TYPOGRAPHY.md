UNPLND Typography System

Version 1.0

Purpose

Typography is the voice of the interface.
Users should immediately understand:
What is important.
What is secondary.
What requires action.
Good typography removes confusion.
Bad typography creates friction.

Philosophy

Readable first.
Beautiful second.
Never sacrifice readability.
Typography should disappear into the experience.
The user should never think about fonts.

Success
Completion

Paragraph Width

Maximum readability.
Avoid huge text blocks.
Split long information into sections.
Whitespace is part of typography.

Emoji Rules

Emoji are allowed.
But intentionally.
Maximum:
One emoji per message.
Never stack emojis.
Never use emojis inside navigation.
Never use emojis as icons.

Writing Style

Short.
Friendly.
Confident.
Never robotic.
Never corporate.
Never over-explain.
Example
Good
Ready for tonight?
Bad
Please configure your personalized activity preferences.

Golden Rule

Every sentence should sound like it was written by a thoughtful human.
Not by software.

Claude Instructions

Whenever generating text:
Prefer fewer words.
Never sound technical.
Never use marketing buzzwords.
Always choose the simpler sentence.
If two options exist...
Choose the warmer one.
Typography and copywriting together define the personality of UNPLND.
Protect that personality.
