# Profil-Header Bilder

Leg deine Hintergrundbilder für den Profil-Header **genau hier** ab
(`assets/profile-headers/`) und benenne sie exakt so:

| Dateiname        | Vibe                          |
|------------------|-------------------------------|
| `sunset.jpg`     | Warmer Sonnenuntergang / Himmel |
| `skyline.jpg`    | Stadt bei Nacht / Skyline     |
| `ocean.jpg`      | Meer / Küste                  |
| `mountains.jpg`  | Berge / Natur                 |
| `forest.jpg`     | Wald / Grün                   |
| `city-lights.jpg`| Nachtleben / Neon             |

Du musst **nicht alle** liefern — leg rein was du hast, sag mir welche,
dann verdrahte ich genau diese als Profil-Themes.

**Empfehlung:** Querformat, mind. ~1200×800 px, `.jpg`. Über dem Bild
liegt automatisch ein dunkler Verlauf (Scrim), damit Name/Bio immer
lesbar bleiben — die Bilder dürfen also ruhig hell/detailreich sein.
